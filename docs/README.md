# TutorLink Documentation
 
Technical documentation for the TutorLink system — both the [backend](https://github.com/jameswilmiller/TutorLinkBackEnd) (this repo) and the [frontend](https://github.com/jameswilmiller/TutorLinkFrontEnd).
 
| Document | Covers |
| --- | --- |
| [architecture.md](architecture.md) | System topology, request lifecycle, authentication flow, booking state machine |
| [data-model.md](data-model.md) | Entity-relationship diagram and the reasoning behind the schema |
| [api.md](api.md) | API conventions, resource groups, auth, error envelope, pagination |
| [decisions/](decisions/) | Architecture Decision Records, the significant technical choices, alternatives considered, and trade-offs accepted |
 
**Suggested reading order:** architecture → data model → decisions. The API doc is reference material rather than reading material.
 
These documents describe how the system works and why it is built this way. Setup and running instructions live in each repo's README.
